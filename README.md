# KP Data Solutions

Static consultancy website ready for GitHub Pages.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `kp-data-solutions`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. GitHub will provide the live URL after deployment.

Note: the contact form is currently a demo. Connect it to a static-form provider or other backend before accepting enquiries.
